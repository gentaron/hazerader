予測手法とデータソース
  1. CAMS（Copernicus 大気監視サービス / ECMWF）の化学輸送モデル予報：排出・化学反応・越境輸送を物理的に計算。
  2. 気象駆動の多ホライズン・リッジ回帰：過去92日の時系列から、混合層高×風速（換気能）、降水、湿度、850hPa のモンスーン気流、日周期・週周期と PM2.5 の関係をリード時間ごとに学習。ECMWF・GFS・ICON の3つの数値予報で個別に駆動し、アンサンブル化。
  3. 減衰持続＋日周期モデル：直近の水準と学習済みの日内変動。
  4. 逆MSE重み付けブレンド：ホールドアウト検証と、毎日自動で行う過去予測の答え合わせ（指数加重）で重みを更新。予測区間の幅も検証結果で自動キャリブレーション。
  5. 地上観測によるバイアス補正（WAQI トークン設定時）と NASA FIRMS の火災ホットスポットによる風上火災負荷（キー設定時）。
  6. 要因分析・ヘイズ診断・検証成績から、根拠つきの日本語解説と健康アドバイスを自動生成。

すべて無料のデータと無料の GitHub Actions / Pages だけで動いています。データ: Open-Meteo (CAMS / ECMWF / NOAA GFS / DWD ICON)、任意で WAQI・NASA FIRMS。AQI は US EPA 2024 基準。これは研究・情報提供目的の予測で、公式の DOE (APIMS) 発表の代わりにはなりません。
